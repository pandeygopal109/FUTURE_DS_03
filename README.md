# FUTURE_DS_03
# Task 3: Marketing Funnel & Conversion Performance Analysis

## Overview
This repository focuses on marketing analytics, assessing lead drop-off rates across each stage of the acquisition pipeline from initial ad impressions to paid conversions.

## Key Insights
- **Top Drop-Off:** The largest loss of potential customers occurs between Website Visits and Lead Generation.
- **Conversion Efficiency:** The end-to-end conversion rate from impression to paying customer stands at **0.34%**.
- **Recommendation:** Optimize landing page content and call-to-action forms to improve lead capture rates.

## Project Deliverables
- `funnel_analysis.py`: Script calculating conversion percentages, drop-off rates, and funnel metrics.
- `funnel_performance_chart.png`: Visual overview of funnel stages.
